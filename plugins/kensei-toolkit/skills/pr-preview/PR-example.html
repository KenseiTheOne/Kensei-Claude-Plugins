Fix greeting + add tests + bump deps

Summary

greet() threw when called with empty or whitespace-only input because it assumed name was always a non-empty string. This PR adds a guard, falls back to "stranger", adds test coverage, threads the fix through the CLI entry point, and bumps the patch version.

Changes

  • Guard greet() against empty / whitespace / undefined name; default to "stranger".
  • Add tests/greet.test.js covering the four input shapes.
  • Surface the guard via the CLI by removing a now-redundant pre-check.
  • Bump package.json to 1.4.1.
