Fix greeting to handle empty name

Summary

greet() throws on empty input because it assumes name is always a non-empty string. This PR adds a guard and falls back to "stranger".

Changes

  • src/greet.js — guard against empty/undefined name, default to "stranger"
  • src/greet.js — trim whitespace before the length check

Files changed

Try it: drag your cursor across any code block below and press Ctrl+C (or ⌘C). Paste into a text editor. The line numbers never show up — they're rendered by CSS ::before pseudo-elements and are not part of the document text.
src/greet.js
// Tiny greeting helper used by the CLI and the web entry point.
// Keep this module dependency-free so it can run in any environment.
export function greet(name) {
return `Hello, ${name}!`;
const safe = (name ?? "").trim();
if (!safe) return "Hello, stranger!";
return `Hello, ${safe}!`;
}
export function farewell(name) {
return `Goodbye, ${name}!`;
}
